📊 Working with Pandas DataFrames

A Python-based Student Performance Analysis project using Pandas, Matplotlib, and Tkinter to analyze student data and visualize meaningful insights.

🚀 Features

- 📂 Read student data from CSV files
- 🐼 Perform data manipulation using Pandas DataFrames
- 📈 Visualize data using Matplotlib charts
- 🖥️ Interactive GUI built with Tkinter
- 📊 Analyze student performance data
- 🎓 Demonstrate fundamental data science concepts

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Tkinter
- CSV Dataset

📁 Project Structure

Working-with-Pandas-DataFrames/
├── main.py
├── students.csv
└── README.md

Note: Replace "main.py" with your actual Python filename if necessary.

⚙️ Installation

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the project folder

cd Working-with-Pandas-DataFrames

3. Install the required libraries

pip install pandas matplotlib

4. Run the application

python main.py

Ensure that "students.csv" is available in the correct directory before running the application.
